📊 Business Insights 360 – FMCG Sales Analytics Dashboard
🚀 Project Overview

Business Insights 360 is an end-to-end Power BI Sales Analytics Dashboard developed for a fictional FMCG company, AtliQ Hardware.

The dashboard helps business teams monitor sales performance, profitability, customer behavior, and supply chain KPIs. It combines data from multiple sources into one interactive dashboard to support data-driven business decisions.

🎯 Project Objective

The main goal of this project was to:

Build a complete Business Intelligence solution.
Convert raw business data into meaningful insights.
Create interactive dashboards for different business departments.
Help management make faster and smarter decisions.
Improve report performance using DAX Studio.
